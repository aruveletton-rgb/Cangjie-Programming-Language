## 2. 三个候选方案对比

| | **A · Flexus L 2核2G Linux** | **B · Flexus X 2核4G Windows** | **C · ECS 通用型按需** |
|---|---|---|---|
| 首年成本 | **¥68（活动）/ ¥660（原价）** | ¥612—1,812（按两月 ¥102—302 外推） | 按需计费，停机不省钱，长期更贵 |
| 仓颉运行 | 需装 Linux SDK 重新构建 | **现成 Windows 二进制直接跑** | 同 A |
| 构建验证 | **需重跑 35 单测 + 26 HTTP** | 无需 | 需 |
| 备案授权码 | **支持**（官方 FAQ 明确 L 实例可生成） | 支持 | 支持 |
| 内存余量 | 2G，编译期吃紧 | 4G，宽松 | 可调 |
| 运维 | systemd + certbot，脚本化 | PowerShell 脚本，已有 | 同 A |
| 风险 | Linux 构建链从未验证 | 成本高 6—10 倍 | 成本不可控 |

**排除 C**：按需实例适合短期验证，不适合"备案要求包周期 ≥3 个月"的场景。
**排除 B 作为主方案**：成本是 A 的 6—10 倍，唯一优势是"不用重编译"，而这个优势可以用一次 ¥41.62 的按需验证买断。

## 3. 推荐执行路径（两步，把风险前置）

### 第一步：花 ¥41.62 验证 Linux 构建（1 天）

1. 买 **Flexus L 2核2G，按需 1 个月**（约 ¥41.62），镜像选 Ubuntu 22.04 或 openEuler 22.03
2. 装 Linux 版仓颉 SDK（官网下载中心提供 Linux 包，LTS/STS 双通道）
3. 跑 `src/backend/deploy/build-linux.sh`（本次已写），看 35 单测 + 26 HTTP 是否全过
4. **过** → 退掉按需实例，改买包年（¥68 活动价）；**不过** → 保留按需实例继续排查，或退回方案 B

> 这一步是整条路线唯一的"未知"。花 ¥41.62 换确定性，比直接包年再发现编不过要划算。

### 第二步：包年 + 备案 + 部署（W9 起）

1. 买 **Flexus L 包年**（活动 ¥68，原价 ¥660.36；以结算页为准）
2. 注册 `.cn` 域名并实名（¥20—35）
3. 用 L 实例生成**备案授权码**，提交 APP + 网站备案（免费，管局 7—20 工作日）
4. 服务器上：`build-linux.sh` → `package-cloud-linux.sh` → `systemctl enable ict-backend`
5. certbot 申请 Let's Encrypt 证书，Nginx 反代 + 托管 web-demo 静态页（可视化 Demo 同机解决）
6. 设置 `ICT_PUBLIC_ORIGIN=https://<域名>`，服务自动切 `session` 模式
