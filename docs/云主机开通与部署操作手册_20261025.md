## 0. 全景：一共 6 步，你只需要动 4 步

| 阶段 | 谁做 | 你要花的时间 | 外部等待 |
|---|---|---|---|
| ① 准备（实名、学生认证） | 你 | 30 分钟 | 实名 0—2 天 |
| ② 买机 + 验证 Linux 能否编译 | 你（代理给命令） | 1 小时 + 编译等待 | 无 |
| ③ 域名注册与实名 | 你 | 20 分钟 | 实名 1 天 |
| ④ 备案提交 | 你 | 40 分钟 | **管局 7—20 工作日** |
| ⑤ 部署与证书 | 代理 | — | 无 |
| ⑥ 上架提审 | 你（代理备料） | 2 小时 | 1—3 工作日/轮 |

**顺序不能换**：②必须先于③④（先确认能编译，再花钱包年）；④必须早于⑥（备案号是提审前置）。

## 1. 阶段① 准备（30 分钟）

### 1.1 账号实名

1. 登录 <https://www.huaweicloud.com>，右上角头像 → **账号中心**
2. 左栏 **实名认证**
3. 选类型：
   - **个人**：身份证 + 人脸，通常即时通过。后续上架需《个人开发者承诺函》，且**办不了增值电信业务许可**（本项目不需要）
   - **企业/学校**：对公打款最快（约 30 分钟），或用营业执照。名称必须与国家企业信用信息公示系统**一字不差**
4. 提交后等状态变"已实名"

> **这一步决定后面全部写法**。备案表、承诺函、隐私政策主体名、AGC 开发者名称，四处必须完全一致，差一个字就要退回重来。

### 1.2 学生认证（可选，5 分钟）

账号中心 → **学生认证**，用学信网信息。通过后可能解锁学生套餐。

> 别为这个卡住：Flexus L 活动价本身已经很低，学生认证只是可能再便宜一点。**如果认证要等审核，直接跳过，先买机。**

### 1.3 先记下三个信息（后面要反复用）

在记事本里写好，别现找：

```
主体全称（与证件一致）：
证件号码：
手机号（接收核验短信）：
```

## 2. 阶段② 买机 + 验证 Linux 编译（关键一步）

### 2.1 进购买页

控制台 → 顶部搜索框输入 **Flexus** → 选 **Flexus应用服务器L实例** → **购买**。
（产品介绍页：<https://www.huaweicloud.com/product/hecs-light.html>，页面上有"购买"按钮）

### 2.2 逐项怎么选

| 配置项 | 选什么 | 为什么 |
|---|---|---|
| 区域 | **华北-北京四** 或 **华东-上海一** | 离你近、备案属地常见。**注意：若以后要用 MaaS，模型只在贵阳一**，但模型调用走公网 API，不必同区域 |
| 规格 | **2核2G** | 课程演示 + 审核访问足够。4G 只在编译时更宽松，可用 swap 补 |
| 镜像 | **系统镜像 → Ubuntu 22.04** | 手册里的 `apt` 命令按 Ubuntu 写。若只有 openEuler，把 `apt install` 换成 `dnf install` |
| 系统盘 | 40G（默认） | 够用 |
| 带宽/流量包 | 最低档（通常 2—3M + 月度流量包） | 演示流量极小，别升配 |
| 计费模式 | **见下方 2.3** | 这是唯一有不确定性的选项 |
| 购买时长 | 先 **1 个月** | 验证阶段不要包年 |
| 自动续费 | **关闭** | 避免验证失败还继续扣费 |

### 2.3 计费模式：这里有个坑，必须看清购买页

官方定价页的措辞是"包年/包月，按需计费 · **X 实例**支持包年/包月、按需计费"，而 2026-07 的一篇社区文章明确说 **L 实例仅支持包年包月**。两处说法不一致，我不替你赌。

**操作**：购买页看"计费模式"那一栏实际有哪些选项——

- **有"按需计费"** → 选它，买 1 个月量级，验证完随时释放，成本最低
- **只有"包年/包月"** → 选 **1 个月**，这就是你的验证成本（约 ¥40—70，以结算页为准）

两种情况都能完成验证，区别只是钱多几块少几块。**别因为找不到"按需"就以为买错了。**

### 2.4 安全组：只开两个口

购买时或购买后在控制台 → 实例详情 → **安全组**：

| 方向 | 端口 | 来源 | 用途 |
|---|---|---|---|
| 入站 | 22 | **你的公网 IP/32** | SSH，别开 0.0.0.0/0 |
| 入站 | 80 | 0.0.0.0/0 | 证书验证 + HTTP 跳转 |
| 入站 | 443 | 0.0.0.0/0 | HTTPS |

**绝对不要开 38082**。后端设计上只绑 `127.0.0.1`，开了也没用，只会扩大风险面。

### 2.5 连上去，装仓颉 SDK

在你自己电脑的终端（Windows 用 PowerShell 或 Git Bash）：

```bash
ssh root@<你的公网IP>
```

> 首次连接会问 `yes/no`，输 `yes`。密码在控制台"重置密码"里设。

连上后，**逐条执行，每条看输出**：

```bash
# 1) 确认系统
cat /etc/os-release

# 2) 装基础依赖
sudo apt update
sudo apt install -y curl wget git python3 unzip build-essential libssl-dev

# 3) 加 swap（2G 内存编译仓颉很可能不够，先加 2G 保险）
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
free -h          # 应看到 Swap 一行有 2.0Gi

# 4) 下载仓颉 Linux SDK
#    去 https://cangjie-lang.cn/download 取 Linux 包的下载链接，替换下面的 URL
wget -O cangjie.tar.gz "<从官网复制的 Linux 包下载链接>"
mkdir -p /opt/cangjie && tar -xzf cangjie.tar.gz -C /opt/cangjie --strip-components=1
ls /opt/cangjie            # 应看到 bin/ envsetup.sh 等
source /opt/cangjie/envsetup.sh
cjc --version              # 期望 1.0.5
```

**如果 `cjc --version` 不是 1.0.5**：停下告诉我，不要改 `cjpm.toml` 里的版本号硬凑。

```bash
# 5) 下载 stdx Linux 包（同一页面，选 linux_x64 版本）
wget -O stdx.tar.gz "<stdx Linux 包链接>"
mkdir -p /opt/stdx && tar -xzf stdx.tar.gz -C /opt/stdx --strip-components=1
export STDX_DIR=$(dirname $(find /opt/stdx -name 'stdx.net.http.cjo' | head -1))
echo $STDX_DIR
ls $STDX_DIR | head     # 应看到 stdx.net.http.cjo、stdx.encoding.json.cjo
```

### 2.6 拉代码、编译、跑测试

```bash
git clone https://github.com/aruveletton-rgb/Cangjie-Programming-Language.git /srv/ict-src
cd /srv/ict-src/src/backend/deploy
chmod +x *.sh
./build-linux.sh --test
```

**这一步要等几分钟，正常。** 判定只看三条：

| 判定 | 期望 | 不通过怎么办 |
|---|---|---|
| `buildExitCode` | `0` | 看 `audit/backend/*_build_linux/build.log` 报错行 |
| `testExitCode` | `0` | 看 `test.log`，可能是用例依赖本地路径 |
| `binary` | 有路径、有 sha256 | 说明产物路径和我猜的不一样，把 `ls target/release` 结果发我 |

**如果卡在编译被 OOM kill**（日志里有 `Killed`）：swap 已加过就再加到 4G 再试一次。仍失败 → 判定为"Linux 路线不可行"，改买 Windows 主机（方案 B），不要在这上面耗超过一天。

### 2.7 验证通过后

- 记下 `binary` 的 sha256
- 如果买的是按需 → **先别释放**，等部署跑通再释放
- 如果买的是 1 个月包月 → 直接进入阶段③，一个月内完成部署

## 3. 阶段③ 域名（20 分钟 + 实名 1 天）

### 3.1 注册

控制台搜索 **域名注册** → 输入想要的域名 → 选 `.cn`（首年约 ¥20—35）。

**命名建议**（要避开上架的"泛词"问题，同时给应用留名字）：

```
campus-<你选的词>.cn
<你选的词>campus.cn
```

不要用 `campusassistant.cn` 这种"类别词+功能描述"——应用名会被判泛词，域名虽不受此限，但名字最好一起想清楚。

### 3.2 实名

注册后立刻做**域名实名认证**（上传身份证/营业执照）。
**域名未实名，备案提交不了**，这是硬卡点。

### 3.3 解析

域名控制台 → 解析 → 添加记录：

| 类型 | 主机记录 | 值 |
|---|---|---|
| A | `@` | 你的公网 IP |
| A | `www` | 你的公网 IP |

验证：本机 `ping 你的域名` 能解析到该 IP（云服务器可能禁 ping，用 `nslookup` 看解析结果即可）。

## 4. 阶段④ 备案（40 分钟提交，7—20 工作日等待）

> **这是唯一不可压缩的等待。11-08（W9）前不提交，第 15 周前"已上架"基本不成立。**

### 4.1 先拿备案授权码

控制台 → Flexus L 实例详情 → **备案** → 生成**备案授权码**（一串字符）。
（官方说明：授权码由 ECS / Flexus X / **Flexus L** 生成，指向该服务器 IP）

### 4.2 提交

打开 <https://beian.huaweicloud.com/> → 开始备案。要提交**两类**：

| 类型 | 填什么 | 备注 |
|---|---|---|
| **网站备案** | 域名、主体、服务器（用授权码） | 隐私政策页需要它 |
| **APP 备案** | APP 名称、**软件包名**、公钥、域名、主体 | 上架必需 |

**APP 备案的坑**：它要**软件包名**和**签名公钥**，而公钥来自发布签名，签名又要在 AGC 建应用之后才能做。所以真实顺序是：

```
AGC 建应用 → 生成发布签名 → 导出公钥 → 提交 APP 备案 → 提审
```

**网站备案可以先做**（只要域名和服务器），不用等签名。建议**先提网站备案**，把 3—5 周的等待先跑起来。

### 4.3 备案期间必须注意

- **管局审核期间网站要关闭解析**（华为云会提示）。所以这期间用 IP 直连调试，别指望域名
- 主体信息、域名实名信息、服务器持有者**三者必须同一主体**，否则退回
- 备案号下来后，要展示在页面底部（`/app/` 页脚），提审会看

### 4.4 你要交给我什么

备案号下来后，把这两项发我（不需要给账号密码）：

```
APP 备案号：
ICP 备案号：
```

我把它写进配置与隐私政策页，再继续部署。

## 5. 阶段⑤ 部署（代理做，你只需给三样东西）

你提供：

```
公网 IP：
域名：
SSH 方式（建议：把公网 IP 加进安全组 22，并给我一个临时账号；或你自己执行我给的命令）
```

我执行（对应 `docs/deploy_runbook_20261025.md` 第 5—9 步）：

1. `package-cloud-linux.sh` 打包
2. 部署到 `/opt/ict-cloud`，写 `runtime.env`（含 `ICT_PUBLIC_ORIGIN=https://你的域名`）
3. `systemctl enable --now ict-backend`
4. Nginx 反代 + Let's Encrypt 证书
5. 托管 `/app/`（Web 演示）与 `/privacy`（隐私政策）
6. 跑 10 条上线验收

**我不会碰的**：你的模型 API Key、账号密码、支付信息。Key 由你自己写进 `runtime.env`，我只检查变量名是否齐全。

## 6. 阶段⑥ 衔接上架

部署验收通过后，按 `docs/备案与上架材料包_20261025.md` 走：

1. AGC 建应用（包名、应用名此时必须已定稿）
2. 生成发布签名（DevEco 26 可走云管理证书自动重签）
3. 导出公钥 → 补 APP 备案
4. 上传 release `.app` → 合法性检测 → 云测试
5. 填 15 项发布信息（材料包里有逐项表）
6. 提审（1—3 工作日/轮）

## 7. 避坑清单（按踩中概率排序）

| # | 坑 | 后果 | 怎么避 |
|---|---|---|---|
| 1 | 安全组开了 38082 | 后端仍只绑回环，等于白开，还扩大风险面 | 只开 22/80/443 |
| 2 | 域名没实名就提交备案 | 提交不了，白等 | 注册后立刻实名 |
| 3 | 主体名四处不一致 | 备案/上架反复退回 | 证件名逐字复制，别手打 |
| 4 | 直接包年再验证 | 编不过就白花一年钱 | 先 1 个月 |
| 5 | 2G 内存不加 swap 编译 | OOM，误判"Linux 不行" | 先加 2G swap |
| 6 | 备案期间还挂域名解析 | 管局审核不通过 | 按提示关解析 |
| 7 | 服务器到期忘了续 | 备案可能失效、审核机连不上 | 开续费提醒，别让它在提审期到期 |
| 8 | 把 API Key 贴进聊天/文档 | 泄露 | Key 只写进服务器上的 `runtime.env`（`chmod 600`） |
| 9 | 为了省钱买 1核1G | 编译必挂，演示也卡 | 最低 2核2G |
| 10 | 买完没关自动续费 | 验证失败仍扣费 | 购买时关闭，验证通过后再按需开 |
